1. Project Overview

This project involves designing and simulating a secure network infrastructure for a modern hospital using Cisco Packet Tracer. It interconnects key departments such as Emergency, Administration, Clinics, and Laboratories to ensure reliable communication. The architecture uses VLANs for network segmentation and security measures like Port Security and SSH to protect sensitive patient data.

2. Project Objectives

  • Design a scalable network topology integrating all hospital departments.
  • Implement VLANs to segment traffic and secure medical data.
  • Configure reliable routing and IP schemes for efficient connectivity.
  • Deploy security features like Port Security and SSH to protect infrastructure.

7. High Availability & Wireless

EtherChannel

Configured between core switches using LACP to aggregate physical links into a single logical link for higher bandwidth and link redundancy.

HSRP Redundancy

Configured between core routers to provide default gateway redundancy using a Virtual IP with Active and Standby roles.

WLAN Integration

Wireless Access Points (AP) integrated using WPA2-PSK security to enable safe mobility for medical devices and laptops.

8. PAT (Port Address Translation / NAT Overload)

8.1 Design / Configuration

NAT Overload (PAT) was configured on the edge router to allow internal hosts to share a single public IP address for secure internet access.

Edge Router Configuration

en
conf t
int g0/0/0
 ip add 192.168.100.1 255.255.255.0
 no sh
 ip nat inside
int g0/0/1
 ip add 209.165.200.233 255.255.255.252
 no sh
 ip nat outside
exit
access-list 1 permit 192.168.0.0 0.0.255.255
ip nat inside source list 1 int g0/0/1 overload

router ospf 1
 network 192.168.100.0 0.0.0.255 area 0
 default-information originate
exit
ip route 0.0.0.0 0.0.0.0 209.165.200.234

Internal / ISP Router Configuration

en
conf t
ip route 0.0.0.0 0.0.0.0 209.165.200.233

int g0/0/0
 ip add 209.165.200.234 255.255.255.252
 no sh

10. Challenges & Solutions

Challenge Root Cause Solution
HSRP status verification returned blank output Verification commands were executed from the wrong interface or from global configuration mode. Verified commands on the correct gateway interface while in privileged EXEC mode.
NAT translation table showed empty results The table was checked before any traffic had traversed the router. Generated test traffic with a ping from an internal PC to populate the translation entries.
Show commands failed inside config mode Monitoring commands were run from the global configuration prompt (config#). Exited to privileged EXEC mode using 'end' before running the commands.
EtherChannel bundle mismatch error Conflicting channel-group mode or speed/duplex settings across the physical ports. Ensured matching mode settings (e.g., active/active) across all bundled physical interfaces.
